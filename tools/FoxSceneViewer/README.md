# Fox Scene Viewer

Static Three.js viewer for `*.foxscene.json` packages generated by `tools/FoxScenePackager`.

Serve the repository or this directory over HTTP, then open:

```powershell
python -m http.server 18080
```

```text
http://127.0.0.1:18080/tools/FoxSceneViewer/index.html
```

To load a generated package directly:

```text
http://127.0.0.1:18080/tools/FoxSceneViewer/index.html?scene=/path/from/server/root/mbqf_stage.foxscene.json
```

Relative GLB URIs in a scene file are resolved relative to the scene JSON URL. For local files opened with the file picker, use absolute `http(s)` or `data:` asset URIs.

For huge scenes, the viewer loads the manifest first and only materializes layer node trees when a layer is loaded. Use:

- `autoload=none` to inspect the manifest without loading GLBs.
- `layers=<name-or-id-substring>` to auto-load one area.
- the layer filter plus `Load` button to load a bounded batch.

Example for an exported AFGH package served from `D:\`:

```powershell
python -m http.server 18081 --bind 127.0.0.1 --directory D:\
```

```text
http://127.0.0.1:18081/github/FMDL-Studio-v2/tools/FoxSceneViewer/index.html?scene=/BOTW/MGSV/EXPORTED/Assets/tpp/level/location/afgh/afgh_stage.foxscene.json&layers=afgh_village_asset
```
